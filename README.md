# Border Radius Previewer

An interactive and lightweight web application that allows users to preview and test CSS `border-radius` values in real-time.

## 🚀 Features

- **Real-Time Preview:** Updates the corner radius dynamically as the slider value changes.
- **Fast & Minimal:** Built with zero external dependencies or package requirements.
- **User-Friendly UI:** Simple, intuitive interface with clean controls.

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

## 📦 Getting Started

To run the project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Kaaner4x/border-radius-previewer.git
   ```
2. Navigate into the project directory:
   ```bash
   cd border-radius-previewer
   ```
3. Open `index.html` in any modern web browser.
